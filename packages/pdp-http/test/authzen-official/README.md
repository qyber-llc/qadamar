# Official AuthZEN Todo decision vectors

The four JSON files in this directory are unmodified copies from the OpenID AuthZEN working group's `authzen` repository:

- Source: `https://github.com/openid/authzen/tree/main/interop/authzen-todo-backend/test`
- Source commit: `05dc553` (downloaded 2026-11-06)
- Files: `decisions.json`, `decisions-authorization-api-1_0-00.json`, `decisions-authorization-api-1_0-01.json`, and `decisions-authorization-api-1_0-02.json`
- Upstream runner: `interop/authzen-todo-backend/test/runner.ts`

These files are test data only. The upstream runner and its dependencies are not copied or executed.
