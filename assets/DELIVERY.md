## Run the operator console

Requirements: Node.js >=22.18, pnpm. From the extracted `qadamar-source` directory:

```sh
pnpm install --frozen-lockfile
bash scripts/delivery/start-demo.sh
```

Open http://127.0.0.1:8789. Sign in as `amira`. On first start, the generated password is written to `data/runtime/qadamar/INITIAL-CREDENTIALS.txt`, readable only by the current user. Credentials and runtime data are excluded from the delivery.

The demo pins the clock to 2026-11-08T10:00:00Z so grants remain meaningful. It binds to loopback. This is not a production security profile; use docs/DEPLOY.md and docs/CONFIGURATION.md for production.

## Run the website

From the extracted delivery folder:

```sh
python3 -m http.server 8794 --bind 127.0.0.1 --directory website
```

Open http://127.0.0.1:8794. Video controls, downloads and English captions require HTTP serving. The local console link works only on the computer running the demo.

The site’s CASE-7 explorer displays six exact engine fixture results generated by `node scripts/delivery/build-demo.ts`. It is explicitly labelled as a recorded build-time simulation, not a live authorization service. The operator console supports new simulations.
